PHOENIX V36.4 - SỬA BẢNG QUY ĐỊNH SAU KHI ADMIN ĐÓNG/MỞ

Thay file app.js trên GitHub bằng file này.

Bản sửa:
- Khi Admin đóng: ẩn form, đồng hồ, tiến độ và bảng quy định.
- Khi Admin mở lại: bảng quy định tự hiện lại để người dùng tick.
- Theo dõi updated_at của tournament_settings, nên vẫn nhận ra Admin vừa đổi trạng thái
  kể cả trang không kịp thấy trạng thái đóng trước đó.
- Khi mới vào trang và đăng ký đang mở: luôn hiện bảng quy định.
- Lịch thi đấu vẫn ở đầu trang.

Kiểm tra sau khi upload:
1. GitHub app.js phải có dòng: select("registration_open,updated_at")
2. Chờ Vercel deployment Ready.
3. Mở cửa sổ ẩn danh để thử.
