# Phoenix V22 — Tournament Control

## Tính năng

- Kiểm tra dữ liệu trước khi công bố:
  - Đủ 12 đội
  - Top 1–12 không trùng
  - Kill không âm
  - Tổng Kill đội khớp Kill cá nhân
- Công bố kết quả từng trận
- Khóa / mở khóa kết quả
- Sao lưu tự động
- Hoàn tác hoặc khôi phục snapshot
- Trang chủ chỉ hiển thị các trận đã công bố
- Bấm vào đội trong BXH để xem chi tiết từng trận
- MVP từng trận

## Cập nhật

1. Upload ghi đè toàn bộ V22 lên GitHub.
2. Chạy `repair_v22_tournament_control.sql` trong Supabase.
3. Tải lại Admin và trang chủ.
