# Phoenix Summer Cup V9 Final

## Tính năng mới

Trang Admin có thể chuyển từng thành viên sang đội khác.

- Chọn đội mới trong danh sách.
- Bấm “Chuyển đội”.
- Không cho đội vượt quá 4 thành viên.
- Danh sách công khai cập nhật theo đội mới.
- Tên đội do Admin đặt vẫn được giữ nguyên.

## Cập nhật GitHub

Upload và ghi đè toàn bộ file trong thư mục V9.

Các file quan trọng:
- admin.html
- admin.js
- styles.css

## Cập nhật Supabase bắt buộc

1. Vào Supabase → SQL Editor.
2. Mở file `repair_v9.sql`.
3. Copy toàn bộ và bấm Run.
4. Chờ hiện `Success`.
