# Phoenix V33 — Smart Swap

## Tính năng
- Kéo vào khoảng trống: chuyển tuyển thủ.
- Kéo thẳng lên thẻ tuyển thủ khác: đổi chỗ hai người.
- Hai đội đều đủ 4/4 vẫn đổi được.
- Swap chạy trong một transaction Supabase.
- Có nút Hoàn tác trong 8 giây.
- Đội đầy hướng dẫn thả lên một người để đổi.
- Hiệu ứng riêng khi sẵn sàng swap.

## Cập nhật
1. Upload toàn bộ file V33 lên GitHub.
2. Chạy `repair_v33_smart_swap.sql` trong Supabase.
3. Tải lại Admin.

Không xóa dữ liệu cũ.
