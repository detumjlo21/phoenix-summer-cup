# Phoenix V32 — Admin Pro Kanban

## Tính năng mới
- 12 đội hiển thị dạng lưới.
- Kéo thả thẻ tuyển thủ qua lại giữa các đội.
- Tự lưu ngay khi thả.
- Không cho thả vào đội đủ 4 người.
- Đổi tên đội trực tiếp trên đầu cột.
- Đổi logo ngay trên đầu cột.
- Nhập Kill ngay trên thẻ tuyển thủ.
- Lưu toàn bộ Kill bằng một nút.
- Tìm tuyển thủ theo tên game hoặc Facebook.
- Ẩn các khu quản lý đội kiểu cũ.
